Nguyên tắc bảo mật

API key được gửi thẳng từ trình duyệt tới Edge Function của Đam San và lưu trong Supabase Vault. Sau khi lưu, trình duyệt chỉ nhận chuỗi che dạng ••••ABCD; hệ thống không có API đọc lại khóa đầy đủ.

Provider tùy chỉnh chỉ cho phép HTTPS công khai. Địa chỉ localhost, private network và metadata endpoint bị chặn. API key không được lưu trong localStorage/sessionStorage. Provider trung gian tương thích OpenAI chỉ cần Base URL + API key + Model ID; không cần sửa mã nguồn.

Thêm nhà cung cấp

Cấu hình nâng cao — Custom JSON / timeout / mapping

JSON này không dùng để chứa API key. Với CUSTOM_JSON_HTTP có thể khai báo generation_path, request_template, response_text_path, response_id_path, timeout_ms. Placeholder hỗ trợ: {{model}}, {{prompt}}.

Model của provider đang chọn

Model discovery chỉ là tiện ích. Với provider trung gian không có endpoint /models, có thể nhập Model ID thủ công và khai báo capability/parameter riêng.
